# 6.13 MeV ROI Method

最终论文数据以固定 ROI 下的净峰面积为统一指标。固定 ROI 应由一份高统计基准谱确定，并记录基准模型、NPS、拟合范围、GEB、拟合中心、sigma、FWHM、ROI 边界、本底模型和近似统计不确定度。

当前 GEB 为 `0.01723 0.02424 0`，采用：

```text
FWHM(E) = a + b * sqrt(E + cE^2)
```

在 6.13 MeV 的理论 FWHM 约为 0.077245 MeV，即 77.25 keV。

## Reference mode

1. 读取一份高统计 D50H75 基准 F8 谱；
2. 在 6.13 MeV 附近进行 Gaussian + linear background 拟合；
3. 得到 mu、sigma 和 FWHM；
4. 扫描不同 `k*sigma` ROI；
5. 综合峰包含率、净峰面积和统计误差确定唯一 ROI；
6. 写入 `fixed_roi.json`。

## Apply mode

读取 `fixed_roi.json`，对所有 T、H、D 和 Detector 模型使用完全相同的 ROI 与本底规则。Apply mode 不允许重新优化 ROI。

当前 `fixed_roi.json` 状态为 `pending`，其中边界为 null，表示尚未产生正式固定 ROI，不是缺失值被当成零。

现有 T/H/D 与 NPS 表是 Gross ROI 历史结果，不能在没有执行统一本底扣除的情况下改称净峰面积。
