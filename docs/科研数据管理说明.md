# 科研数据管理说明

## 原始数据原则

原始历史目录 `F:\东华理工大学研究生\MCNP\mcnp5\模拟总数据` 是只读数据源。Git 项目中的文件均为整理副本。任何输入、输出、CSV 数值和 Origin 工程均不得反向覆盖原始目录。

## 工况组织

一个 MCNP 工况对应一个完整文件夹，内部使用 `Origin/`、`代码输入/`、`结果输出/` 和 `数据处理/`。跨工况对比统一放在阶段的 `总结数据/`，不混入单工况目录。

## 输出匹配

输出归属至少检查 `i=`、标题、NPS、几何、`F8:P 1`、`E8 0 1599I 16`、`FT8 GEB 0.01723 0.02424 0` 和完成历史数。标题与实际 NPS 不一致时保留原文，并在 inventory 中记录，不能静默修正。

## 输出脱敏

本地原始 outp 不改动。公开副本只把超算账户主目录替换为 `<REMOTE_HOME>`。生成后通过本地反向替换逐字比较，确认除该路径外内容不变。原始和公开 SHA256 分别记录在 `output_manifest.csv`；公开仓库不记录真实超算账户路径。

## 指标边界

历史旧探测器表格中的 `6.03-6.23 MeV` 求和是 Gross ROI。未来 D50H75 正式结果使用固定 ROI 下的 `6p13NetPeak`。两者不得混名或直接替换。
