# Output Matching Audit

## 当前项目目标输出

本次严格匹配了 44 份目标输出：厚度 10、长度 14、距离 8、NPS Disk 10、D50H75 探测器 2。

- 42 份具有对应输入，已通过 `i=`、几何、NPS、探测器、F8、GEB 和正常结束标志核对。
- 2 份 D50H75 输出的输入已由用户主动删除；输出身份明确，但 `output_matched=no`。
- 当前目标集合中没有无法确定对应模型的输出。

## 未纳入当前项目的历史输出

全盘候选搜索还发现 Point 源对照、FullSpec 两阶段模型、O-16 数据库敏感性测试、其他材料和临时测试输出。它们的研究目的不同，不属于当前 Phi10 mm Disk 源 T/H/D/NPS 主线，因此没有复制，也不作为 unmatched。

## 安全限制

正式超算输出内部包含超算用户目录路径。项目本地保留原样副本，但当前通过 `.git/info/exclude` 阻止其进入 Git 索引；未生成篡改内容的“伪原始输出”。
