# Generation 1: Legacy Detector

本目录来自原始历史数据 `模拟总数据`，用于保存早期 CaO 厚度、长度、距离和 NPS 收敛研究。

历史探测器输入卡采用：

- LaBr3 晶体：`4 RCC ... 5.08 ... 2.54`，即直径 5.08 cm、长度 5.08 cm；
- Al 外壳：外半径 3.0 cm、总长度 5.48 cm；
- 没有 D50H75 模型中的 PTFE 层。

因此本目录结果不能写成 D50H75 最终优化结果。评价指标主要是 `6.03-6.23 MeV` 内 21 个 F8 bin 的直接求和，即 Gross ROI，不是 Net Peak Area。

目录包括 WATTS 配置、厚度 10 个工况、长度 14 个工况、距离 8 个工况、最终计数 15 个工况及跨阶段总结。历史长度建议 H30 与后续实际 H25 条件同时保留，不在整理阶段裁决。
